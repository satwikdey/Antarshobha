# Image Guide for Antarshobha Website

This guide provides specifications for all images needed for the Antarshobha Interior Design Studio website.

## 📏 General Image Specifications

### Quality Standards
- **Format**: JPG for photos, PNG for graphics with transparency
- **Quality**: High resolution (minimum 1920px width for hero images)
- **Compression**: Optimized for web (under 500KB per image)
- **Style**: Professional, clean, modern aesthetic matching brand colors

### Brand Color Palette for Photo Selection
- Primary Gold: #D4AF37
- Charcoal Gray: #36454F
- Muted Green: #8FA68E
- Warm White/Cream tones: #FEFDF8, #F7F5F3

## 🎨 Image Style Guidelines

### Photography Style
- **Lighting**: Natural light preferred, well-lit spaces
- **Composition**: Clean, uncluttered shots
- **Angles**: Professional architectural photography angles
- **Focus**: Sharp, high-quality images

### Color Treatment
- **Warmth**: Warm color temperature (3000K-4000K)
- **Saturation**: Natural saturation, not oversaturated
- **Contrast**: Good contrast without being harsh
- **Consistency**: Consistent editing style across all images

### Content Guidelines
- **Spaces**: Clean, styled, lived-in but not cluttered
- **Furniture**: High-quality, contemporary pieces
- **Decor**: Sophisticated accessories and art
- **People**: When included, professional and approachable

## 📱 Responsive Considerations

### Multiple Sizes
For key images, consider creating multiple sizes:
- **Large**: 1920px width (desktop)
- **Medium**: 1024px width (tablet)
- **Small**: 600px width (mobile)

### Optimization
- Use image compression tools (TinyPNG, ImageOptim)
- Consider WebP format for modern browsers
- Implement lazy loading for better performance

## 🔄 Image Implementation

### Replacing Placeholders
Once you have the images, replace the placeholder divs in the HTML:

```html
<!-- From this placeholder: -->
<div class="image-placeholder">
    <i class="fas fa-home"></i>
    <p>Modern Living Room</p>
</div>

<!-- To actual image: -->
<img src="images/portfolio/residential-1.jpg" alt="Modern Living Room Design">
```

### Adding New Images
1. Save images in appropriate folders
2. Update HTML src attributes
3. Add descriptive alt text for accessibility
4. Test on different screen sizes

## 🎯 Tips for Best Results

1. **Hire a Professional**: Consider hiring an interior photographer
2. **Staging**: Properly stage spaces before photography
3. **Consistency**: Maintain consistent style across all images
4. **Brand Alignment**: Ensure images reflect the "Inner Beauty" philosophy
5. **Quality Over Quantity**: Better to have fewer high-quality images
